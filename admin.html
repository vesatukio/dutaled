Keamanan penting

GitHub Pages tidak memiliki server rahasia. Untuk menulis ke GitHub, masukkan Fine-grained Personal Access Token milik Anda. Token hanya disimpan sementara di memori halaman ini dan tidak disimpan ke localStorage. Jangan gunakan token dengan akses ke repositori lain.

Buat token GitHub

Pengaturan token: pilih hanya repositori dutaled dan beri izin Contents: Read and write. Tidak perlu izin Issues, Actions, atau Administration.

Hubungkan token untuk mengaktifkan simpan ke GitHub.
