# Volix PWA

Aplikasi stok dan estimasi laba untuk Android, tanpa Supabase dan tanpa Excel. Data tersimpan lokal di browser perangkat.

## Akses
Setelah GitHub Pages memperbarui situs, buka `/volix/` pada domain yang sama dengan situs Dutaled.

## Instal Android
Buka URL `/volix/` di Chrome Android saat online, menu ⋮ > Tambahkan ke layar utama / Install app. Buka sekali saat online untuk menyimpan cache offline.

## Fitur
Katalog SKU/variasi, modal, harga, diskon penjual, stok, stok masuk, penjualan dengan konfirmasi, cegah nomor pesanan ganda, estimasi omzet/biaya/laba, serta cadangan/pemulihan JSON.

## Batasan
Data hanya tersimpan di satu browser/perangkat. OCR foto otomatis belum tersedia; isi SKU, Qty, dan nomor pesanan secara manual. Tarif biaya Shopee perlu disesuaikan dengan rincian aktual. Pajak, retur dan rekonsiliasi biaya belum ditangani. Buat cadangan berkala.
